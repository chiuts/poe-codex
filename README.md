# 🏛️ POE Codex 秘典庫

這是流亡黯道（Path of Exile）個人研究知識庫與賽季拓荒資料庫，提供跨裝置查閱、機制分析報告與圖解指南。

---

## 📁 核心分類導覽

- **`00_正式架構與版本`**  
  研究所憲法、治理規則、入庫標準與資料衝突優先級規範。

- **`01_拓荒備戰`**  
  各賽季極速拓荒、首發流派指南與實戰手冊。第一層按賽季分類，內含圖解 PDF 及同名附屬資料庫（PoB 代碼、離線網頁與速刷筆記）。

- **`02_流派研究`**  
  流派深度機制研究、底層物理實算、各職業配置橫向評測與分析報告。

---

## 🛠️ 維護規範
- **PoB 物理實算**：數值依據本機 Path of Building 核心原碼驗證。
- **繁體中文正名**：專有名詞依據 Garena 台服官方字典庫校正。
