# 🏛️ POE Codex 秘典庫

這是你的 POE 研究所本地正式中央檔案庫。

## 📁 12 大分類資料夾
- 00_正式架構與版本 - 研究所憲法、治理規則與入庫標準
- 01_現役BD         - 當前運作中的流派正式快照與研究報告
- 02_歷史BD         - 過去賽季/版本的流派留存
- 03_機制研究       - 遊戲底層公式、傷害倍率與防禦機制研究
- 04_版本與PN       - 官方 Patch Notes 與改版影響分析
- 05_PoB原始資料    - 原始 XML 與 Base64 代碼備份（永不竄改）
- 06_已確認Bug與模型缺口 - 已確認的遊戲 Bug 或 PoB 計算缺失
- 07_待驗證         - 待實戰測試之假設與邊界條件
- 08_使用者糾錯     - 禁止復活區（AI 曾講錯且被糾正的紀錄）
- 80_待研究BD投遞   - 未處理之臨時 PoB、截圖與筆記投遞箱
- 90_AI待整併       - AI 剛產出但尚未經架構審核之暫存區
- 99_歷史封存       - 淘汰之舊架構與過期規則
